The critic / value head. Baseline = group mean/std instead of V_φ(s).
5. Why LoRA ⇒ TRL/PEFT?
PKU has no LoRA (future plan). Full FT needs 8× A800. LoRA fits cluster budget.
6. Start 1.5B then 3B — where?
biggpu for real runs. Colab = smoke only (tokenizer/LoRA attach).
