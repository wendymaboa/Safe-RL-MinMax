03 · One reply

The score arrives after the reply is finished.

  1. The policy samples a full reply. Temperature 1, one sequence, up to 512 tokens. Nothing is halted mid-generation.
  2. Beaver reward and Beaver cost each return one number, the end score. Harm is not marked on individual tokens.
  3. If cost > 0, that one reward number is replaced. Tokens before the last one still carry only the KL term, −0.02 log(π / πref).
  4. The bounds are then expanded from the raw helpfulness scores of this batch. The replaced values do not enter Vmin or Vmax. KL does not enter them either.
  5. γ = 1. The return is undiscounted. GAE λ = 0.95 only shapes the advantage.

safe:   r ← rRM
unsafe: r ← Vmin − Vmax

This is the RLHF bandit: one score at the last token. It is also the point I want to hold beside ROSARL later. Their main experiments stop the episode when the state becomes unsafe. Here the episode is the finished string.

If someone asks whether the penalty is smeared across harmful tokens: no. end_scores, then scatter onto the last token. I checked this after a wrong reading of the code.

05 · PKU Safe RLHF

Their update still sees cost on the safe side of zero.

advantage = (AR − λ AC) / (1 + λ)

One global λ, one threshold, every prompt. λ grows when a window of episode costs sits above the threshold. A helpful-but-harmful reply can still win if its reward advantage beats λ times its cost advantage. That is deliberate. A model that refuses everything is safe and useless, which is the balance their paper is built around.

06 · The thing I cannot separate

Two gaps. They predict different next runs.

The reward on the safe side

  1. A reply with cost ≤ 0 never sees the penalty.
  2. It is trained on Beaver helpfulness.
  3. On this prompt, refusing scores about −3.8, so the high reward sits near the boundary.
  4. The policy can walk up to the threshold from the safe side. The penalty only labels what has already crossed.

Prediction. A method that charges cost on every reply, including cost ≤ 0, should not follow the path from about 14% unsafe to about 64%.

The episode does not stop

  1. ROSARL’s guarantee is for an unsafe state that ends the episode.
  2. Here the cost is known only once the string exists.
  3. Replacing the terminal score relabels that string. It does not cut the trajectory short.
  4. The next batch is a new draw.

Prediction. PPO-Lag also scores finished strings and does not halt. If termination is the break, its unsafe rate should look like C.
